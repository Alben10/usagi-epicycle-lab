# 타원으로 그린 우사기

정적 HTML, CSS, JavaScript로 구성된 교육용 시뮬레이션입니다. `data.json`은 제공된 기존 사이트에서 추출한 윤곽선 및 푸리에 계수입니다.

로컬에서는 이 폴더에서 `python -m http.server 8000`을 실행한 뒤 `http://localhost:8000/`에 접속하세요. 데이터 로딩에 fetch를 사용하므로 파일을 직접 여는 방식은 브라우저에 따라 제한됩니다.

GitHub Pages 배포: 이 폴더의 파일들을 저장소 루트에 올리고 저장소 Settings → Pages에서 브랜치 배포를 설정합니다. 경로는 상대 경로이므로 프로젝트 저장소에서도 작동합니다.

최소제곱 계산은 동일 간격 샘플과 정수 주파수의 직교성을 이용합니다. 각 타원의 방향, 위상 및 회전 방향은 기존 푸리에 계수에서 정하며 공통 이심률을 적용한 뒤 장반축만 음이 아닌 값으로 최적화합니다. 점 인덱스별 평균 제곱 오차가 목적 함수이며 평균 거리와는 다릅니다.
